# dsh-info-check 0.2.2

本版本聚焦“过程可见、里程碑有序”。

## 任务进度

- 输入框上方新增任务进度条，每个里程碑是一块原创线描石碑。
- 进度按整个任务向前推进；接近下一块石碑时停住等待验收，验收时快速到达，交付后隐藏。
- 鼠标悬停石碑显示里程碑标题。
- 进度按会话保存，刷新、切换会话、fork/resume 可恢复。
- 里程碑计划确认后数量锁定，任务结束前不再增加或减少。
- 进度条右侧 × 或 `/dsh-info-check reset` 可清除已结束任务的进度条。

## 复盘与质量标准

- 交付确认后生成任务复盘，统一追加到一个 `retrospectives.md`，并在交付结果中返回复盘摘要。
- 设置里增加质量标准输入框，保存后写入 `quality-standard.md` 的手工补充区。
- 设置里增加台账、复盘分析、质量标准的文件位置入口。
- 验收事件落盘，插件重载后仍能生成完整复盘。
- 每 3 次任务更新一次用户工作质量标准，自动注入后续任务。
- 可关闭自动复盘；关闭后交付时询问是否复盘。

## 监督与验收

- 严格门禁（默认）：验收文件必须在上一里程碑验收之后修改，避免把后续工作提前做完再连续验收。
- 仅提醒：只保留策略提示，不阻止验收。
- 验收后可以继续同一轮做下一个里程碑，不需要中断对话；下一个里程碑必须使用新修改的文件。

## 其他

- 离线自检：`node scripts/self-check.mjs`、`scripts/self-check.ps1` 和 `/dsh-info-check selfcheck`。
