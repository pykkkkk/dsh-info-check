# dsh-info-check 0.2.2

本版本聚焦“过程可见、里程碑有序”。

## 新增

- 输入框上方的任务进度条：每个里程碑是一块线描石碑，进度按会话保存，悬停显示标题，交付后隐藏，可手动清除。
- 任务复盘：交付后写入本地复盘文件，并返回简短摘要。
- 用户工作质量标准：根据复盘更新，注入后续任务；设置里可直接填写自己的质量要求。
- 设置中的台账、复盘分析、质量标准文件位置入口。
- 安装自检与更小的安装测试脚本。
- 监督方式：严格门禁或仅提醒。

## 改进

- 里程碑计划确认后数量固定，任务结束前不增删。
- 验收必须对应新完成的文件或脚本，避免把后续工作提前做完再连续验收。
- 验收后可以继续同一轮工作，不需要中断对话。
- 复盘事件会保存，重载后仍能还原完整过程。

## 修复

- 历史会话不会再因进度数据损坏而加载失败。
- 设置中的文件位置入口可以正常打开。
- 进度和复盘统计在编辑、重试和重载后保持一致。

- 更多跨平台验证。
- 可选的团队任务列表集成。
