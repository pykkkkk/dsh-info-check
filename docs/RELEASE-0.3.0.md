# dsh-info-check 0.3.0

本版本把一次任务升级为一份小型工程合同：用户是甲方，agent 是乙方。

## 新增

- **任务书**：目标、质量要求、范围外和里程碑先由甲方审核。
- **预算方案卡**：紧接着任务书，总预算和每个里程碑预算都以人民币元（CNY）直接修改；里程碑用 `m1`、`m2` 固定编号，内容输入框只填内容，剩余部分为备用预算。
- **两轮确认**：甲方确认第一轮后，乙方思考并给出调整说明，第二轮确认后才签约。
- **预算使用卡**：上半部分按行拆成“文本 + 数据”两列；下方先显示该里程碑的初始预算，再显示累计已用；是否追加预算是卡片内的选择题，选择追加才显示金额输入。
- **预算结算**：以财务报表表格展示，并由甲方评价预算是否合理。
- **成本来源**：优先接入 `@kenz1117/dsh-ui-usage-billing` 的实测 CNY 成本；没有该插件时从会话日志的 token 用量估算。
- **预算标准**：从历史结算中学习报价和追加偏好，用于后续报价参考。
- **完整流程图**：见 `docs/FLOW.md`。

## 质量与成本

- 质量由任务书、验收证据和交付确认管理。
- 成本由初始预算、阶段使用、追加审批和结算管理。
- 预算未签约不能执行；预算审核未完成不能进入下一里程碑。

## 升级

```sh
npm install dsh-info-check@0.3.0
```

适用于 DSH `0.2.x`，验证版本 `0.2.2-rc.3`。
