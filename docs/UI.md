# dsh-info-check 浮窗设计说明

## 设计北极星

**一张安静的检查台**：用户在这里不是读报告，而是在 agent 的理解上做一次小修改，然后决定“可以了”。界面要让人一眼看到“这是 dsh-info-check 在问我”，把注意力留给那段可编辑的文字和唯一的主按钮。

设计基线：DeepSeek Blue 单一强调色、8px 圆角为主、拆掉卡片套卡片、保留阅读区而不是满屏边框。

## 呈现形式

- 对话正中央的**浮窗**：半透明遮罩（`rgba(15,23,42,.30)`）+ 自适应卡片，14px 圆角。
- 尺寸：宽度自适应，默认 560px，**最大 `min(75vw, 75vh)`**；高度随内容，**最大 75vh**。四边都不超过对话窗口的 3/4。
- 可拖动右边缘调整宽度；最大宽度等于当前浮窗高度。双击右边缘恢复默认宽度。
- 右上角 X：表示**跳过**，不是取消任务。点击后提交 skip 答案，Host 按 agent 原始版本继续下一阶段；不会重新弹卡或结束任务。
- 文本排版：每个要点一个独立文本框/只读框，左侧有单独的序号框（1、2、3…）；可编辑框与只读报告一致，文本框随内容自动增高。每张确认卡末尾有备注输入栏。
- 细节题：单选再次点击取消，多选可多选/取消；每个选项题下方有“其他”自由输入框，内容进入 answer custom。
- 卡片是白底表面（`#FFFFFF`），阅读区是近白（`#FAFBFC`），没有卡片套卡片。
- 关闭按钮在右上；评审浮窗点击遮罩不关闭，设置浮窗点击遮罩关闭。
- 运行环境缺少 `react-dom` 的 portal 时，退化为输入框内的卡片。

## 四个确认点

四张浮窗共用同一套外壳，区别只在标题、正文和底部动作：

| 浮窗 | 时机 | 底部动作 |
|---|---|---|
| 需求核对 | 开工前 | 确认复选框 + 取消 / 下一步；第二步是细节选择题 |
| 里程碑确认 | 需求核对后**一次** | 确认复选框 + 按此方案执行；倒计时 + 停止计时 |
| 里程碑验收 | 每个里程碑完成后 | 只读报告 + 确认复选框 + 验收通过；另有“需要返工”（返修说明浮窗）和“暂停任务”；可选结果文件链接；倒计时 + 停止计时 |
| 交付确认 | 最终结果呈现前 | 只读报告 + 确认复选框 + 确认并交付；另有“需要调整”，打开调整说明浮窗；倒计时 + 停止计时 |

验收/交付的报告内容只读；用户输入的是“返修说明/调整说明”，提交后作为 feedback 交给模型修改。次按钮是幽灵按钮，主按钮仍是唯一的品牌色按钮。

## 结构

```
┌──────────────────────────────────────────┐
│ [dsh-info-check]  需求核对     ── 1/2   ×  │
│ 下面是 agent 的理解与核对单…              │
│ ┌──────────────────────────────────────┐ │
│ │ 我的理解                               │ │
│ │ [独立文本框]                           │ │
│ │ 完成标准                               │ │
│ │ [独立文本框]                           │ │
│ └──────────────────────────────────────┘ │
│ ──────────────────────────────────────── │
│ ☑ 我已确认以上理解         [取消] [下一步] │
└──────────────────────────────────────────┘
```

- 顶部：灰色 `dsh-info-check` 徽标、17px 标题、细线步骤条（40×2）+ `1 / 2`、28px 关闭按钮。
- 描述：12.5px Slate，位于头部与正文之间。
- 正文：第一步是**按小标题拆开的独立文本框**（我的理解 / 完成标准 / 范围外 / 里程碑），每个标题下一个近白文本域，可分别修改；不是一整块大 textarea。小标题使用 **15px 纯黑粗体**，比文本框里的 13px 正文更大。
- 第二步是题组（灰色小标签 + 问题 + 8px 圆角选项）。
- 里程碑浮窗同一套结构：第一段固定是 `里程碑`（显示“m1 — 主要工作”），接着是 `方案`、`影响范围`，都按小标题拆成独立文本框；没有小标题时退回一个整体文本框。
- 底部：确认复选框在左，主操作在右；`取消/上一步` 是幽灵按钮，`下一步/提交/按此方案执行` 是主按钮。
- 里程碑浮窗同一套结构，步骤显示 `1 / 1`；底部只保留确认复选框和“按此方案执行”。倒计时条右侧有 **“停止计时”**：点击后倒计时停止、浮窗不关闭，用户改完再确认。
- 里程碑验收：正文是 `里程碑 / 完成内容 / 验证证据 / 未完成或风险 / 结果文件` 的**只读**分段报告；底部是确认复选框 + “需要返工”（幽灵）+ “暂停任务”（幽灵）+ “验收通过”（主按钮）；倒计时 + 停止计时。点“需要返工”会在上层再打开一个 **“返修说明”浮窗**，用户填写理由后提交。结果文件段显示为可点击路径，点击调用 `/dsh-info-check open <绝对路径>`，在 Explorer 中选中文件。
- 交付确认：正文是 `完成程度 / 交付内容 / 未完成或限制 / 验证` 的**只读**分段报告；底部是确认复选框 + “需要调整”（幽灵）+ “确认并交付”（主按钮）；倒计时 + 停止计时。点“需要调整”会打开 **“调整说明”浮窗**。
- 设置浮窗：标题“设置”；正文分为「当前对话 / 偏好 / 自动计时 / 核对与台账」，使用分段按钮（里程碑 1–5）、三张期望卡片（完美/较好/及格）、数字输入 + 预设（30/60/90/120 秒）、开关和台账路径；底部是恢复默认 / 取消 / 保存设置。当前对话开关只影响本会话，其余字段写入全局 Config。

## 配色

| 用途 | 色值 |
|---|---|
| 主色（唯一强调色） | `#4D6BFE` |
| 主色深态（hover/文字） | `#3B55D4` |
| 主色浅底（选中态） | `#EEF1FF` |
| Ink（标题/主文本） | `#1F1F1F` |
| Slate（辅助文本） | `#64748B` |
| 三级文本 | `#94A3B8` |
| 页面底/徽标底 | `#F5F6F8` |
| 卡片表面 | `#FFFFFF` |
| 阅读区 | `#FAFBFC` |
| 分隔线 | `#E5E7EB` / `#EFF1F4` |
| 边框 | `#D7DCE3` |
| 倒计时告警 | `#B45309` |
| 错误 | `#DC2626` |

主色只承载两处：**主操作按钮**、**选中/勾选态**；其余中性。没有装饰性渐变、插画或第二种强调色。

## 动效

| 位置 | 效果 |
|---|---|
| 遮罩 | 160ms 淡入 |
| 卡片 | 180ms：透明度 + 6px 上移 + .995 缩放 |
| 按钮/选项 | 按压 `scale(.94)`，弹簧 `cubic-bezier(.34,1.56,.64,1)` |
| 波纹 | 按钮/选项按下时从指针位置扩散，450ms 消失 |
| 复选框 | 勾选时弹到 `scale(1.12)`，对勾用 stroke-dashoffset 画出 |
| 步骤条 | 宽度 300ms 过渡 |
| 倒计时条 | 宽度 1s 线性；最后 10 秒变告警色 |
| 减少动态 | `prefers-reduced-motion: reduce` 下关闭动画与过渡 |

## 开关

- 位置：**“创造模式”旁边**——新会话时在 New Session 行、创造模式控件右侧；进入会话后在标题旁的“创造模式”标签右侧（`conversation.session.header.actions`，order -9，紧跟 preset 标签的 -10）。
- 形态：小开关 + **下划线文字**“需求核对”；**没有外框、没有胶囊底**。
- 点击“需求核对”文字打开设置浮窗；点开关只切换当前对话。
- 开关关掉后，当前对话的策略段与相关工具消失；其他对话不受影响。

## 无障碍与响应式

- 复选框用隐藏原生 input + 自定义盒，键盘可聚焦，有品牌色 focus ring。
- 关闭按钮有 `aria-label`；选项按钮有 `aria-pressed`；文本域有 `aria-label`。
- 卡片最大宽度 `min(75vw, 75vh)`、最大高度 75vh；正文滚动、底部操作固定；窄屏下按钮可换行；右边缘可拖动调宽。
- 窗口高度低于 640px 时同样遵守 75vh 上限；内容短时卡片自动收短。
- 使用 Urbanist → Segoe UI → 系统字体回退；中文走 PingFang/微软雅黑。
