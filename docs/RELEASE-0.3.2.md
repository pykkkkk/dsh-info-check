# dsh-info-check 0.3.2

本版本重点补齐里程碑验收的第三方监理、预算交互和长任务等待体验。

## 新增

- **监理子 Agent**（设置中可选）：每个里程碑验收前，由独立监理按已确认合同审查完成内容、证据、边界和遗留问题。
- **三档监理信号**：
  - `accept`：直接进入验收；
  - `minor`：主 agent 按清单小修后再次验收，不再回传监理；
  - `major`：重大返工，修改后重新提交监理。
- **同一对话复用监理**：保留前序里程碑上下文，并持久化监理子 Agent id，避免每检查一次就新建。
- **审计轻量模式**：开启监理时，审计只做关键一致性复核，并重点检查 minor 修改是否落实、其他细枝末节是否遗漏。
- **任务进度汇报**：主 agent 在执行过程中用一两句普通正文说明正在做什么，不弹卡。
- **工具/后台超时设置**：默认 180 秒，可设 30–3600 秒；超时先中止并查原因，复杂任务可临时放宽 1–3 分钟。
- **任务档案手风琴**：台账中同时只展开一个任务。

## 修复

- 修复 `accept_milestone` 监理分支引用未注入的 `currentSettings` 导致的验收失败。
- 第二轮预算卡不再在轮询时重置甲方修改的总预算和里程碑金额。
- 预算实时曲线和任务进度条点 × 后收起为浮标，点击可恢复，不再只能关闭。
- 审计与监理等待现在受超时设置约束，不会无限干等。
