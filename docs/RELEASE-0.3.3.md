# dsh-info-check 0.3.3

这是 0.3.2 的补丁版本，整理预算浮窗位置和工具超时约束。

## 修复

- 预算入口移动到对话右上角 header 工具区；
- 点击图标打开浮动预算窗，再次点击或点 × 关闭；
- 浮窗停在右侧边栏左侧，不再直接覆盖任务档案；
- 工具调用和后台 bash 任务使用硬超时：
  - 默认 180 秒，可在设置中调整 30–3600 秒；
  - 到点中止等待，后台任务由 `jobs.kill` 实际终止；
  - 超时后 agent 需要先分析原因，再调整方式或临时放宽时间；
- 监理、审计等子 agent 不受工具超时限制。

## 验证

- 隐私检查：0 项发现。
- 单元、回归和客户端 smoke：47 项通过。
- 兼容 DSH `0.2.2-rc.5`。

## 升级

```sh
npm install dsh-info-check@0.3.3
```

安装后在 DSH 中重新加载插件并刷新页面。
