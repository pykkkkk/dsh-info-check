# dsh-info-check 0.3.1

本版本把任务档案、预算预测、情况对接和边界核对补齐为一条可追溯的执行链。

## 新增

- **任务档案**：每个任务一个条目，任务号采用 `YYMMDDHHmm` 十位数字；展开后先看到任务内卡片目录，再按卡片查看任务书、预算、时间线、验收、预算审核、交付和结算。
- **任务档案标签页**：台账、质量标准、预算标准；标准页直接读取并保存 `.dsh-info-check/*-standard.md`。
- **预算预测**：`forecast_budget` 根据里程碑复杂度、文件数、测试数和质量要求，按当前模型的 CNY/百万 token 单价预测 token 与预算；第一轮预算必须带预测。
- **实时预算曲线**：预算签约后，右侧面板显示任务级累计费用，并用红色虚线标出各里程碑累计预算。
- **情况对接 SDK**：`situation_check` 提供只读问题、Agent 建议和用户意见输入；倒计时或关闭后继续执行，行动写入任务台账。
- **边界硬门禁**：验收必须声明边界是否变化；发生变化但没有 `situation_check(kind=boundary)` 的用户回答通过时，验收被拒绝。
- **可选审计 agent**：交付和结算卡弹出前，可由子 agent 对照执行记录核对内容是否如实。
- **设置分栏**：当前对话开关与全局默认值分开。
- **全局语言**：自动 / 中文 / English，覆盖设置、任务档案、插件弹窗、进度和控件文案。
- **系统提醒**：插件弹窗出现前使用浏览器 Notification API 在 Windows 右下角提醒。

## 修复

- 预算使用卡按任务签约基线计算，不再把整段会话历史费用计入新任务。
- 预算结算显示任务级实际使用，并保留财务报表。
- 设置保存不再被空质量标准同步误报为失败。
- 任务档案的内容过长问题通过两级目录解决。

